# clitor

Я устал прописывать эти конфиги вручную, поэтому clitor.

Если меня еще что-то утомит, возможно функционал расширится.

Небольшая CLI-утилита, которая переключает git-идентичность в текущем репозитории:
пишет `user.name`, `user.email` и `core.sshCommand` в **локальный** конфиг git.
Если текущий каталог ещё не репозиторий — выполняется `git init`.

## Сборка

```sh
just build
```

## Использование

```sh
clitor            # интерактивный выбор профиля (стрелки / j,k / Enter)
clitor bill       # применить профиль bill сразу
clitor -list      # список профилей
```

Клавиши в меню: `↑`/`↓` или `j`/`k` — навигация, `Enter` — применить,
`q` / `Esc` / `Ctrl+C` — отмена. Если ввод не с терминала, вместо меню
будет предложен ввод номера.

Дополнительно:

```sh
clitor -config ~/dotfiles/config.yml bill
```

## Конфиг

Конфиг всегда берётся из `$XDG_CONFIG_HOME/clitor/config.yaml`
(обычно `~/.config/clitor/config.yaml`). Другой путь можно указать явно
через `-config`; если такого файла нет — утилита завершается с ошибкой.

При первом запуске без `-config`, если конфига ещё нет, clitor создаёт его
из шаблона (все профили закомментированы), просит отредактировать файл и
завершается с кодом 1.

```sh
mkdir -p ~/.config/clitor
cp config.example.yaml ~/.config/clitor/config.yaml
```

Формат:

```yaml
users:
  bill:
    name: bill             # git user.name
    email: bill@gates.ru   # git user.email
    key: id_bill           # имя ключа в ~/.ssh или путь к ключу
```

Поле `key` превращается в:

```
ssh -i ~/.ssh/id_bill -o IdentitiesOnly=yes
```

Абсолютные пути используются как есть, `~/...` раскрывается в домашний каталог,
а любой относительный путь (включая просто имя файла) разрешается относительно
`~/.ssh/`, например `keys/id_work` → `~/.ssh/keys/id_work`.

Если файл ключа не найден, профиль **не применяется** — команда завершается
с ошибкой. В списке профилей (`-list` и меню выбора) отсутствующий ключ
подсвечивается красным (отключается через `NO_COLOR=1`).

## Что именно меняется

Только локальный конфиг репозитория (`.git/config`), глобальные настройки
git не затрагиваются:

```sh
git config --local user.name  "<name>"
git config --local user.email "<email>"
git config --local core.sshCommand "ssh -i <key> -o IdentitiesOnly=yes"
```
